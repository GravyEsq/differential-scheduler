# מערכת שיבוצים דיפרנציאליים

מערכת סטטית לבניית שיבוצים, עריכה ידנית, בדיקת התנגשויות וייצוא דוחות.

המאגר מכיל את המערכת בלבד ואינו כולל נתוני תלמידים או מורים. קובצי פרויקט נטענים מקומית בדפדפן, נשמרים ב־localStorage ואינם נשלחים לשרת.

## פרטיות

- אין להוסיף למאגר קובצי Excel, דוחות, גיבויים או קובצי פרויקט אמיתיים.
- `dist/schedule-data.js` חייב להישאר קובץ נתונים ריק בלבד.
- לפרויקט אמיתי יש להשתמש בכפתור "טעינת קובץ פרויקט" לאחר פתיחת האתר.
